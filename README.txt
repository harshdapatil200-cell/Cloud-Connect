CLOUDCONNECT - SIMPLE CLOUD WEB APPLICATION

Files:
1. index.html  - Main webpage
2. style.css   - Website design
3. script.js   - JavaScript interaction

How to test locally:
- Keep all three files in the same folder.
- Open index.html in a web browser.

Google Cloud hosting:
Option 1: Cloud Storage (static website)
- Create a Cloud Storage bucket.
- Upload index.html, style.css and script.js.
- Configure the bucket according to your lab instructions for public/static website access.

Option 2: App Engine
- For a static HTML/CSS/JS app, follow Google's current App Engine deployment instructions.
- A suitable app.yaml/runtime configuration may be required depending on the selected runtime.
